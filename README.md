# 中药学题库 · 在线练习

把《中药学》单元练习表整理成可直接刷题的单页网站，无需登录、无需联网后端。

**在线地址：<https://wangji330330-ops.github.io/114/>**

## 功能

- **按单元练习**：总论 + 各论 23 个单元，可多选单元自由组合
- **即时判分**：点选项立刻标出对错并给出正确答案
- **选项注解**：作答后在每个选项下方标出该药的实际功效/主治；若选项本身是一句功效，则反标「这是哪味药的功效」
- **题目数量**：10 / 20 / 50 / 全部，随机或按顺序出题
- **错题本**：答错自动收录，答对自动移出，可单独重练
- **收藏夹**：标记重点题，随时回看
- **查题**：按题干、选项、知识点关键词检索（1506 题全量，本地匹配，支持全文）
- **进度统计**：每个单元的已练题数与正确率，累计作答与总正确率
- **深色模式**：跟随系统，也可手动切换
- **移动端优化**：手机上可「添加到主屏幕」当小应用用

快捷键（答题页）：`1`–`5` 选选项，`Enter` / `→` 下一题，`←` 上一题，`F` 收藏。

## 题库说明

数据来自一份《中药学》题库压缩包（41 个「题目导入模板」Excel，含两套互为副本的文件）。

处理口径：

| 环节 | 说明 |
| --- | --- |
| 原始行 | 4180 行（含表头、分组标记、共用选项行） |
| 去重键 | 题干（去空白/编号/标点）+ **正确答案文本** |
| 最终题量 | **1506 题**，全部为单选题，每题 4–5 个选项 |

之所以不只用题干去重：「麻黄的功效是（）」这类模板题干在不同单元重复出现，且各副本选项顺序不同，只用题干会把不同的题并成一道、也会把同一道题留下多份。加入「正确答案文本」后，同一道题的不同副本会正确合并，选项不同的题则各自保留。

题库原文为录入稿，个别题目存在错别字（如「地愉」应为「地榆」）、选项与题干不匹配等瑕疵，已在页面标注「以教材为准」。发现明显错题欢迎提 Issue。

### 选项注解从哪来

题库本身没有「解析」字段，所以注解是**从题库自身反推**的，没有引入外部生成的医学内容：

- 「X的功效是（）」「X的主治病证是（）」的正确答案 → 药名 → 功效 / 主治
- 「具有 A、B 功效的药物是（）」的正确答案 → 药名 → A、B
- 「治疗 <证候> …的药物是（）」的正确答案 → 药名 → 该证候

最终得到 254 味药的对照表，覆盖约 60% 的选项、80% 的题目；覆盖不到的选项不显示注解，宁缺勿错。

由于是从题目文本里抽出来的，个别药名下的功效可能只截取了片段（例如某题只提到「补火助阳」就只记这一条）。这类数据适合做「回忆提示」，不能替代教材。

## 目录结构

```
index.html              单页应用入口
assets/data.js          题库数据 + 药物小词典（window.QB，约 333 KB）
assets/app.js           交互逻辑（无框架、无依赖）
assets/style.css        样式
assets/icon.svg         图标
manifest.webmanifest    PWA 清单
tools/build_data.py     Excel -> data.js 的生成脚本（含药物知识挖掘）
```

## 本地预览

`index.html` 用的是普通 `<script>`，直接双击打开即可（`file://` 也能跑）。若要用本地服务器：

```bash
python -m http.server 8000
# 打开 http://localhost:8000/
```

## 更新题库

```bash
pip install xlrd openpyxl        # .xls 需要 xlrd，.xlsx 需要 openpyxl
python tools/build_data.py --src <Excel 所在目录> --out assets/data.js
```

脚本会按「第X单元」自动归属单元、补齐 B 型题的共用选项、按上述规则去重，并重新生成 `assets/data.js`。同一份输入重复运行结果完全一致。

## 数据与隐私

答题记录只保存在浏览器 `localStorage`（键名 `zyx.qb.v1`），不上传任何服务器。换设备或清理浏览器数据会丢失进度。
