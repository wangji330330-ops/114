# 中药学题库 · 在线练习

把《中药学》单元练习表整理成可直接刷题的单页网站，无需登录、无需联网后端。

**在线地址：<https://wangji330330-ops.github.io/114/>**

## 功能

- **按单元练习**：总论 + 各论 23 个单元，可多选单元自由组合
- **即时判分**：点选项立刻标出对错并给出正确答案
- **选项注解**：作答后在每个选项下方标出该药的实际功效/主治；若选项本身是一句功效，则反标「这是哪味药的功效」
- **题目数量**：10 / 20 / 50 / 全部，随机或按顺序出题
- **错题本**：答错自动收录，答对自动移出，可单独重练
- **收藏夹**：标记重点题，随时回看
- **查题**：按题干、选项、知识点关键词检索（1506 题全量，本地匹配，支持全文）
- **进度统计**：每个单元的已练题数与正确率，累计作答与总正确率
- **深色模式**：跟随系统，也可手动切换
- **其他题型**：名词解释 65 条（总论概念 + 各论分类）、病例问答 151 个（病例题改写）、多选题 120 道（同功效药物辨析）、问答题 208 道（性味归经与功效）
- **移动端优化**：手机上可「添加到主屏幕」当小应用用；浏览器/系统返回键在页面内逐级返回，不会直接退出站点

快捷键（答题页）：`1`–`5` 选选项，`Enter` / `→` 下一题，`←` 上一题，`F` 收藏。

## 题库说明

数据来自一份《中药学》题库压缩包（41 个「题目导入模板」Excel，含两套互为副本的文件）。

处理口径：

| 环节 | 说明 |
| --- | --- |
| 原始行 | 4180 行（含表头、分组标记、共用选项行） |
| 去重键 | 题干（去空白/编号/标点）+ **正确答案文本** |
| 最终题量 | **1506 题**，全部为单选题，每题 4–5 个选项 |

之所以不只用题干去重：「麻黄的功效是（）」这类模板题干在不同单元重复出现，且各副本选项顺序不同，只用题干会把不同的题并成一道、也会把同一道题留下多份。加入「正确答案文本」后，同一道题的不同副本会正确合并，选项不同的题则各自保留。

题库原文为录入稿，个别题目存在错别字（如「地愉」应为「地榆」）、选项与题干不匹配等瑕疵，已在页面标注「以教材为准」。发现明显错题欢迎提 Issue。

### 选项注解从哪来

作答后每个选项下面会显示该药的两行信息：

- **功效**：`石膏：清热泻火，除烦止渴，敛疮生肌，收湿止血`
- **性味归经**：`甘、辛，大寒 · 归肺、胃经`

数据来自 `assets/herbs.json`（470 味药的教材口径数据，含性味、归经、功效、分类、别名），构建时与题库交叉：

1. 药名能对上 → 直接用教材条目；
2. 对不上（药组、冷门药）→ 用题库答案反推的说法兜底；
3. 选项本身是一句功效（如「发汗解表，宣肺平喘，利水消肿」）→ 反查这是哪味药的功效，只认功效词完全一致的，避免误判；
4. 同一题里两个选项功效完全一样 → 互标「（与 X 易混）」；
5. 查不到的选项就不显示注解，宁缺勿错。

已知局限：教材条目覆盖约 56% 的选项；题库与教材个别表述不一致时以教材为准，但题目自身的答案仍按原题库保留。

## 目录结构

```
index.html              单页应用入口
assets/data.js          题库数据 + 药物词条（window.QB，约 372 KB）
assets/app.js           交互逻辑（无框架、无依赖）
assets/style.css        样式
assets/icon.svg         图标
manifest.webmanifest    PWA 清单
assets/herbs.json       教材药物数据（470 味：性味/归经/功效/别名）
assets/extra.js         名词解释 / 病例问答 / 多选题 / 问答题（window.QB_EXTRA，约 102 KB）
tools/build_data.py     Excel -> data.js 的生成脚本
tools/build_extra.py    生成 extra.js（名词解释手写，其余由题库与教材数据生成）
```

## 本地预览

`index.html` 用的是普通 `<script>`，直接双击打开即可（`file://` 也能跑）。若要用本地服务器：

```bash
python -m http.server 8000
# 打开 http://localhost:8000/
```

## 更新题库

```bash
pip install xlrd openpyxl        # .xls 需要 xlrd，.xlsx 需要 openpyxl
python tools/build_data.py --src <Excel 所在目录> --out assets/data.js --herbs assets/herbs.json
```

脚本会按「第X单元」自动归属单元、补齐 B 型题的共用选项、按上述规则去重，并重新生成 `assets/data.js`。同一份输入重复运行结果完全一致。

## 数据与隐私

答题记录只保存在浏览器 `localStorage`（键名 `zyx.qb.v1`），不上传任何服务器。换设备或清理浏览器数据会丢失进度。
